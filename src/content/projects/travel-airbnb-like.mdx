This full-stack listings app provides an intuitive interface where users can securely authenticate, browse a variety of items, and save their favourites for later reference. It was an attempt to implement an authentication system using JWT tokens and to fetch data with Axios, complete with client-side caching. Although originally built as part of a course, I adapted it to work with a real backend for a more authentic development experience.
